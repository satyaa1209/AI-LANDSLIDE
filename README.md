# AI-Based Landslide Warning System

## Project Overview
The AI-Based Landslide Warning System is a project designed to analyze environmental and sensor-related data to identify potential landslide risks. It uses machine learning techniques to process data and generate predictions that can help in early warning and risk awareness.

## Features
- Machine Learning based landslide prediction
- Data preprocessing and model training
- Prediction system
- Backend API
- Frontend interface
- Dataset analysis

## Technologies Used
- Python
- Machine Learning
- HTML
- CSS
- JavaScript
- Flask / API
- Pandas
- Scikit-learn

## Project Files
- `app.py` – Main application
- `predict.py` – Prediction functionality
- `train_model.py` – Model training
- `prepare_data.py` – Data preprocessing
- `split_data.py` – Dataset splitting
- `read_dataset.py` – Dataset reading
- `landslide_model.pkl` – Trained machine learning model
- `index.html` – Frontend page
- `style.css` – Styling
- `script.js` – Frontend JavaScript
- `wsn_landslide_data.csv` – Dataset

## How to Run

1. Clone this repository.
2. Install required Python libraries.
3. Run the backend application.
4. Open the frontend in your browser.
